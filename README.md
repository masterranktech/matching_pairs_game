# 🧠 Memory Match - 3D Flip Card Game

A responsive, browser-based memory puzzle game built with Vanilla JavaScript (ES6+), HTML5, and CSS3 3D transforms.

## ✨ Features
- **Dynamic Randomization:** Shuffles cards randomly every round using the Fisher-Yates algorithm.
- **3D Card Flip Animation:** Hardware-accelerated CSS perspective card turns and error shakes.
- **Real-Time Scoreboard:** Tracks moves, seconds/minutes, and calculation of incorrect attempts.
- **Interactive Hint System:** Allows users to briefly flash unflipped cards (3 attempts per game).
- **Fully Responsive:** Fluid board layout adapting from desktop down to mobile viewports.

## 🛠️ Tech Stack
- **HTML5:** Semantic game board layout and modal accessibility.
- **CSS3:** Flexbox, CSS Grid, custom properties, and 3D transforms (`rotateY`).
- **JavaScript:** ES6+ state management, event delegation, and timer intervals.
